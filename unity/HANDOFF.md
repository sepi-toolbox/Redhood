이전에는 약 2MB 폰트의 GitHub 연결 도구 업로드가 완료되지 않아 작업이 지연됐다.
게임에 쓰이는 글자만 남긴 Redhood UI 폰트(약 245KB)로 변경한 뒤 업로드가 정상 완료됐다.
기존 코어/화면 체크포인트는 `37514ddd2b683040e2d6364ce1c900ccef34626c`로 원격에 반영됐다.
그 이후 변경은 현재 브랜치 로그와 PR의 최신 커밋으로 확인한다.

## 이번 단계

족보 연습 모드에서 **늑대 단일 전투**로 확장했다. 적 예고/반격/힘/출혈/리롤 피해,
가중치/쿨다운/연계기/파쇄/국면 전환, 플레이어 HP/승리/패배를 연결했다.
범위는 막/층 1, 계몽 0, 기본 족보 전부 개방, 일반 주사위, 유물/변형 없음이다.
다른 적을 미완성 규칙으로 실행하지 않도록 시작 단계에서 거부한다.

실제 `js/engine.js`를 동일한 난수와 조작으로 재생한 24개 시나리오의 1,044개
상태를 C#과 대조한다. 24개 모두 승패까지 진행되며 늑대의 모든 일반/유니크 행동을 포함한다.
족보 계산은 기존 913개 기준값과 전체 조합 268,912건 대조를 유지한다.
