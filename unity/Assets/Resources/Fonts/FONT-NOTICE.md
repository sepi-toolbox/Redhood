# Redhood UI

Derived from Nanum Gothic Regular, Copyright (c) 2010 NHN Corporation.
Distributed under the SIL Open Font License 1.1 in OFL.txt.
Source: https://github.com/google/fonts/tree/main/ofl/nanumgothic

Modifications: includes characters used in this repository's data, JS and Unity
source strings; removes hinting; renames the font to Redhood UI in accordance
with the source font's reserved names. This reduces the bundled font size.

Rebuild with `python unity/tools/subset-font.py /path/to/NanumGothic-Regular.ttf`
after adding text. Supply the original full font, not this subset.
