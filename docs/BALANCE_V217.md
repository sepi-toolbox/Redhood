# v2.17 밸런스 명세 — 행동 예고 시스템 (인게임 반영·배포 완료)

작성: 2026-08-09. 성권 최종 수정 대기 — 이 문서의 모든 수치는 data/*.json 에 실제 반영돼 있다.
실측: `node test/cardsim2.mjs enc 400` / `node test/cardsim2.mjs run 500`

## 1. 시스템 (눈 능력 폐기 → 예고)

- 적은 매 턴 주사위와 함께 **다음 행동을 예고**한다 (몬스터 머리 위 알약 표시).
- **행동의 위력 = 그 적의 남은 주사위 합** — 내가 주사위를 깎으면 예고 숫자가 그 자리에서 줄어든다.
- 행동 op 6종: `damage`(피해) · `bleed`(피해+출혈, amount 고정) · `armor`(자기 방어도)
  · `lifesteal`(피해+같은 값 회복) · `heal`(자기 회복) · `empower`(다음 턴 자기 주사위 전부 +위력, mult로 감쇠)
- 전략: 공격 예고면 깎고, 방어·회복 예고면 그냥 때린다. 예고 종류가 곧 그 턴의 정답을 비튼다.
- 데이터: enemies.json `battleMoves: [{id,name,op,weight,amount?,mult?,flat?}]` — noRepeat 1 가중 추첨.
- 구 moves/pattern(야찌용)은 휴면 보존. faceAbilities 는 검증에서 금지(폐기 완료).

## 2. 성장 축 (2·3막 구조 문제 해결)

- `cards.json config.acts`: 2막 `diceBonus 1`, 3막 `diceBonus 2` — **내 주사위와 적 눈이 함께** +N.
  (2막: 내 주사위 2~7·추적 카드 →7, 3막: 3~8·추적 →8. 상쇄 경제는 유지되고 숫자만 커진다)
- `acts.json scaling.hp`: 1.0 / **1.7** / **2.15** (구 2.1/3.3 — 예고 체제에 맞춰 하향)
- `config.victoryHeal 5`: 전투 승리마다 HP +5 (소모전 완화 — 런 클리어 33%→56%)

## 3. 44종 구성 원칙

- 일반: n 미지정(혼자5·둘이3 유지), 눈 합(솔로) 10~15. n 명시 적이 페어로 나오면 개수 ×0.6.
- 정예: n 3~4에 큰 눈 — "적지만 아픈 주사위". 눈 합 17~20.
- 보스: n 4~5, 눈 합 19~20 + 정체성 행동 (늑대 = 개과 공통 [2,4,6,7·8] 계열 승계).
- 스웜(쥐떼·모기떼·촛불떼): 눈 [1,2] × n6 — 잔챙이 물량.
- 최종보스: [1,3,5] n3 시작, 2턴마다 +1개 (최대 +4) — 버티기, 10턴 생존 실측 29%.

## 5. 남은 조정 후보 (성권 판단 대기)

- 일반 조우 개별 승률이 100%에 붙어 있다 — 개별 긴장감을 올리려면 눈 합 +1~2씩 (대신 런 클리어 하락).
- 2막 보스 97%가 무른 편 — swamp_king n 4→5 또는 hp 1.7→1.8.
- 3막 보스 69% — 의도보다 낮으면 lucid_king 계열 눈 합 -1.
- 카드 풀 4종 확장(2·3막 전용 카드), 상점·이벤트 보상의 카드 전환 — 별도 과제.
- 편집기(데이터)는 아직 cards/battleMoves 탭이 없다 — 필요 시 추가.
