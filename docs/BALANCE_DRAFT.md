## 1. 핵심 산수 — 이 게임의 밸런스 축

상호 차감 규칙에서는 **막은 1점 = 내 공격력 1점 소모**다. 그래서 전투의 순수 경제는:

```
내 턴당 산출 ≈ 주사위 5d6 기대값 17.5 + 카드 보정 6~8  ≈ 24
적 턴당 산출 S = 적 주사위 합 기대값
턴당 순 진행 ≈ 24 − S   →   전투 길이 = 적HP / (24 − S)
```

- S가 24에 가까울수록 전투가 기하급수로 길어지고, **S ≥ 24면 수학적으로 승리 불가**.
- 적 눈 능력은 S에 안 잡히는 추가 압박(출혈·방어도·흡혈)이므로 실효 S는 표기보다 높다.

여기서 나온 **예산표** (1막, 시작 덱 기준):

| 조우 | 적 주사위 합 S 예산 |
|---|---|
| 일반 솔로 (1~3층) | 10~13 |
| 일반 페어 (4층~) | 합계 14~17 |
| 정예 | 18~20 |
| 보스 | 19~21 |

### 실측 (400판/조우, 500런)

| 조우 | 현행(v2.16) | 시안 B |
|---|---|---|
| 1층 들개 | 99% | 100% |
| 5층 일반2 | 99% | 97% |
| 6층 정예 | 100% | **94%** |
| 12층 늑대 (HP60) | 100% | **85%** |
| 12층 늑대 (HP42 도착) | 96% | **76%** |

현행은 개별 전투가 전부 99~100%로 긴장감이 없는데도 런 클리어가 28.6%뿐 —
**개별 전투가 아니라 소모(attrition)가 죽이는 구조**다 (사망이 4~9층에 고르게 분포).
시안 B는 개별 전투에 실패 확률을 만들고, 대신 §3의 승리 회복으로 소모 곡선을 회복시킨다.

## 3. 런 경제 제안 — 승리 회복 +5

전투 승리 시 HP +5 (빵 부스러기 유물과 별개, 기본 제공). 실측 스윕:

| 승리회복 | 런 클리어 | 보스 도달 | 도착 HP | 보스전 승률 |
|---|---|---|---|---|
| +0 | 32.6% | 41% | 33.5 | 79% |
| +3 | 52.2% | 61% | 46.5 | 86% |
| **+5** | **64.6%** | **74%** | **50.2** | **87%** |
| +7 | 72.2% | 81% | 54.4 | 89% |

시뮬 정책은 유물·상점·이벤트를 안 쓰므로 실플레이는 이보다 높게 나온다. +5 권장.
(대안: 매 층 자동 +3, 휴식 2회 배치 등 — 어느 쪽이든 총회복량 ~40이 목표.)

## 4. 2·3막 — 구조적 문제 (결정 필요 ⚠)

HP 배율을 2.1→1.5, 3.3→2.0으로 낮춰도: 2막 보스 25%, **3막 정예·보스 0%**.
원인은 HP가 아니라 **minBonus**: 3막 정예 눈 4~6 → S = 5.0×5 = **25 ≥ 24 = 승리 불가**.
플레이어 산출이 1막부터 끝까지 고정(5d6+카드4종)이라 어떤 적 수치로도 답이 없다 —
적을 약하게 만들면 1막 재탕, 세게 만들면 불가능.

**플레이어 성장 축이 필요하다. 선택지:**

- **A. 주사위 성장** — 막마다 주사위 면 상향 (1막 d6 → 2막 [2~7] → 3막 [3~8] 또는 개수 5→6).
  현재 dice.json 스킨·효과가 휴면인데, 이 축을 "주사위 획득/강화"로 되살리는 방향과 결합 가능.
  산수: 3막 [3~8]×5 = 27.5 + 카드 ≈ 34 → 3막 예산 S 25~28 성립.
- **B. 카드 성장** — 강한 카드를 2·3막 보상에만 등장 (예: 비용2 "전부 +1", 비용3 "주사위 하나 12로").
  카드 풀 확장은 §5-4 때문에 어차피 필요. 다만 뽑기 운 의존이라 하한 보장이 약함.
- **C. 자원 성장** — 자원 3→4→5, 손패 5→6. 구현 최소(설정값), 체감은 밋밋.

권장: **A(하한 보장) + B(선택의 재미)** 병행, C는 보류.
2·3막 28종 눈 구성은 이 결정 뒤에 설계해야 예산이 정해진다 (지금 하면 두 번 일함).

## 5. 전수검사 결과 (신규칙 기준 데이터 감사)

1. **battleDice 보유: 1/44** (들개뿐). 나머지는 등급 기본값 → 개성 없음. 시안 B가 1막 16종 커버, 2·3막 28종은 §4 결정 후.
2. **휴면·죽은 데이터** (카드 전투가 안 읽음):
   - enemies.json 의 moves/pattern/phases/uniqueMoves/enlightenedMove — 구 야찌 전투 전용 (족보처럼 휴면 보존 OK, 단 신규 적 추가 시 작성 불필요)
   - scoring.json 전체, statuses.json (출혈만 카드 전투가 자체 구현)
   - dice.json 의 effect 전부 — **플레이어 주사위가 ri(1,6) 고정이라 주사위를 얻어도 스킨 외 효과 없음** (§4-A 와 직결)
   - 유물: healOnVictory·coinBonus 만 동작, 족보 참조 유물 전부 무의미
   - **상점·이벤트 보상이 여전히 족보/주사위** — 카드 전투에선 가치 없음. 카드·유물 판매로 개편 필요
3. **엔진 확인 사항**:
   - `dmin`에 `Math.min(4, …)` 클램프 — 눈 하한 5 이상 설정 불가 (의도 확인)
   - faces 검증 1~9 — **d10/d12/d20 불가**. 성권 컨셉(20면체) 위해 검증 완화 + 주사위 UI 두 자리 표시 필요
   - `battleDice.n` 이 페어에서도 그대로 적용 — 쥐떼 n6 페어 시 주사위 12개 (한 줄 초과). "n은 솔로 기준, 페어는 ×0.6" 스케일 규칙 제안
   - 최종보스: 눈 4~6 × (5+최대4)개 = S 36 → 10턴 생존 0%. 버티기 엔딩의 목표 턴 수를 정해야 수치를 잡을 수 있음
4. **카드 풀 4종뿐** — 5번째 전투부터 보상이 덱 희석만 됨. 최소 8~12종으로 확장 필요 (족보를 발동 조건으로 쓰는 카드 포함 — 휴면 코드 부활 지점)
5. **설정 이중화** — act1.json `hpScalePerFloor 0.11`(구 경로) vs cards.json `floorHpScale 0.02`(현 경로). 혼동 방지 위해 구 키 삭제 또는 주석 권장

## 6. 적 버프 변주 (성권 노트 — 엔진 확장 제안)

"못 막은 20면체의 남은 눈만큼 다음 턴 자기 주사위 전부 보정" 류. faceAbilities op 추가안:

| op | 효과 | 예시 |
|---|---|---|
| `empower` | 살아남은 이 주사위의 남은 값만큼 다음 턴 자기 주사위 전부 +N | 북치는 고블린: 8→empower |
| `curse` | 다음 턴 내 주사위 하나 −N | 저주 눈 |
| `pierce` | 이 주사위는 차감 불가(막을 수 없음, 값은 작게) | 유령류 |
| `explode` | 파괴될 때 나에게 N 피해 (막는 데도 대가) | 가시·폭탄류 |
| `summonDie` | 다음 턴 자기 주사위 +1개 | 증식류 |

전부 "이 눈을 막을 것인가"의 의사결정을 비트는 장치 = 게임 컨셉 그대로.
2·3막 눈 구성 설계 때 함께 배정하는 것을 권장.
