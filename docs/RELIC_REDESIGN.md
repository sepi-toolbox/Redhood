# 유물 재설계안 — 32종

성권이 준 네 갈래를 그대로 뼈대로 삼았다.

| 갈래 | 등급 | 성격 |
|---|---|---|
| ① 평평한 효과 | 일반 | 아무 빌드에나 얹힌다. 계산이 필요 없다 |
| ② 평평하지만 코어 자원 | 정예 | 리롤·벼름처럼 판을 굴리는 자원을 준다 |
| ③ 다른 유물·족보와 시너지 | 일반 | 조건이 맞아야 값이 난다 |
| ④ 시너지를 곱하거나 터뜨린다 | 정예 | 빌드가 완성됐을 때 폭발한다 |

## 두 가지 규칙

**상위호환을 만들지 않는다.** 지금 붉은 망토(리롤 +1)와 운명의 골무(리롤 +2)가 정확히 그 관계다.
같은 축을 건드리는 두 유물은 **양을 다르게 하지 말고 방식을 다르게** 한다 —
하나는 매 턴 주고, 하나는 조건이 맞을 때 몰아 준다.

**정예에는 리스크를 섞는다.** 정예가 그냥 더 세면 고를 이유를 고민할 필요가 없다.
값을 치르게 해서 "이 유물에 맞춰 빌드를 튼다"는 결정을 만든다. 치를 값은 네 가지로만 쓴다.

- **최대 HP를 깎는다** — 몸으로 낸다
- **매 턴 자해** — 시간으로 낸다
- **다른 것을 막는다** (특정 족보 봉인·방어도 못 얻음) — 선택지로 낸다
- **조건부로만 켜진다** (HP 절반 이하, 방어도 0일 때) — 상태를 유지하는 대가

## 만들어지는 축 넷

이 배치의 목적은 **일반에서 씨앗을 줍고 정예에서 지붕을 얹는 것**이다.

| 축 | 일반(씨앗) | 정예(지붕) |
|---|---|---|
| **벼름** | 숫돌 · 재 묻은 부싯깃 · 사냥꾼의 눈 | 늑대달 목걸이 · 거머리 반지 |
| **방어** | 마른 장작 | 곰의 등 · 문지기의 빗장 |
| **저체력** | 독사과 조각 | 말라붙은 심장 · (HP를 깎는 정예 전부) |
| **한 족보** | 까마귀 깃털 · 사냥꾼의 부적 · 가죽 장갑 | 은식칼 · 도토리 부적 · 은탄환 · 할머니의 동화책 |

HP를 깎는 정예(운명의 골무·은탄환)가 저체력 축의 **연료**가 되는 게 이 표의 핵심이다.
리스크가 그냥 손해가 아니라 다른 빌드의 입구가 된다.

## 붙이려면 엔진에 하나가 필요하다

지금은 유물 하나에 `hook` 이 **하나**만 달린다. 위의 리스크는 전부
「이득 + 대가」 두 개짜리라, 유물이 훅을 여러 개 가질 수 있어야 한다.

```json
{ "id": "silver_bullet", "hooks": [
  { "type": "categoryMult", "category": "fourKind", "mult": 1.8 },
  { "type": "maxHp", "amount": -10 }
] }
```

읽는 자리는 세 곳뿐이라(`engine.js` 113 · 501 · 827) `hook` 하나짜리도 계속 받게 두고
`hooks` 배열을 함께 보도록 넓히면 된다. 새 훅 종류는 두 개만 있으면 된다 —
`turnSelfDamage`(매 턴 자해)와 `sealCategory`(특정 족보 봉인).

**여기까지가 설계다. 좋다고 하면 붙이고 400판 돌려서 수치를 맞춘다.**
