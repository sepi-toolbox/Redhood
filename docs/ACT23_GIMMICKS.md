# 2·3막 기믹 제안 — 28종 테마 행동 (디자인 확정용 · 미구현)

작성: 2026-08-10 · 전제: v3.7 문법 그대로 — **기믹은 전부 "행동"이고, 행동은 상태이상/지속효과/버프를 남긴다.**
신규 시스템 없음. 신규 엔진 op **0개** (선택 확장 2건만 §4에).

---

## 1. 설계 원칙

1. **사다리** — 1막에서 배운 규칙의 강화형이 2막에, 2막 문법의 "중첩(한 행동에 효과 2개)"이 3막에 온다.
   계승 관계를 노골적으로 드러낸다: 옹이 골렘의 굳히기 → 진흙 골렘 → 비명 지르는 돌.
2. **13종 상태이상 전원 등판** — 1막이 안 쓴 독·저주·축복·기절·부패·잠식·약탈이 2·3막의 새 얼굴이 된다.
   특히 **잠식(devour)** 은 다 차면 공허의 부름만 남는 휴면 기믹까지 되살린다 (무덤 벌레 → 최종보스 서사).
3. **지역 정체성** — 늪=몸에 남는 것(독·세금), 안개=정보(가림·저주), 무덤=잃는 것(기절·잠식·매장),
   꿈=뒤섞임(결속·가림 중첩), 언덕=침식(잠식·약탈), 성당=거꾸로 된 규칙(축복·봉인).
4. **시작 버프 데뷔** — 문턱·상한을 정예 3종에 시작 버프로: 처음부터 두르고 나오는 "몸의 규칙".
5. 예고는 🌀 하나 (v3.7 규칙 유지) — 한 번 맞아보고, 다음부터 행동명으로 읽는다.

## 2. 2막 (12종)

| 몬스터 | 테마 행동 (기존 행동명 재사용) | 효과 | 계승/데뷔 | 돌파 |
|---|---|---|---|---|
| 늪두꺼비 | 독침 뱉기 | 독(poison) ×2 | **독 데뷔** — 그 눈을 족보에 쓰면 눈금만큼 피해 | 독 묻은 눈을 버리는 족보 선택 |
| 모기떼 | 흡혈 | 리롤 세금 1 (2턴) + 피해에 흡혈 | 들개 강화형 | 첫 굴림 승부 |
| 안개 망령 | 곡소리 | 혼란 ×2 | 도깨비불 강화형 | 합계형 족보 |
| 창백한 사슴 | 응시 | 저주(curse) ×2 | **저주 데뷔** — 그 칸은 낮은 눈만 나옴 | 저주 칸을 리롤 재료로 소모 |
| 해골 병사 | 뼈 던지기 | 기절(stun) ×2 | **기절 직격 데뷔** — 족보엔 들어가되 합산 0 | 조합 재료로만 쓰기 |
| 무덤 벌레 | 파고들기 | 잠식(devour) ×1 | **잠식 데뷔** — 양옆으로 번짐, 다 차면 공허의 부름만 | 번지기 전에 처치 (시간 압박) |
| 진흙 골렘 E | 굳히기 + **시작: 상한 18** | 굳음(petrify) 6, 3턴 | 옹이 골렘 강화형 + **상한 버프 데뷔** | 5 이하로 짜는 족보, 잔펀치 |
| 목 없는 기사 E | 고삐 당기기 + **시작: 문턱 12** | 직전 족보 봉인 2턴 | 까마귀 강화형 + **문턱 버프 데뷔** | 로테이션 + 한 방 12 초과 |
| 무덤지기 E | 매장 / 흙을 덮는다 | 물기(lockHigh, 회복 없음) 2턴 / 봉인 ×1 | 강꼬치+빗자루 융합 | 4개 족보 설계 |
| 늪의 왕 B | 늪을 건너라 → (반피) 늪이 끓어오른다 | 상위 족보 봉인(포카드·라지·야찌) 2턴 → 리롤 세금 2 | **곰인형의 반전** — 큰 한 방 금지 | 전반 잔펀치, 후반 속전 |
| 안개의 어머니 B | 장막 → (반피) 자장가 | 어둠(blind) 2턴 → 포박(bind) ×2 | 지하실의 것 강화형 → 구속 국면 | 암산 / 포박 전에 승부 |
| 파묻힌 자 B | 부패 / 무덤의 손 | 부패(rot) ×2 / 홀드 세금 (개당 1) | **부패 데뷔** + 가시덤불 극한형 | 부패 칸 먼저 소모, 노홀드 |

## 3. 3막 (15종 + 최종)

3막 일반부터는 **한 행동에 효과 2개** — 중첩이 기본 문법이 된다.

| 몬스터 | 테마 행동 | 효과 | 계승/데뷔 | 돌파 |
|---|---|---|---|---|
| 악몽 토끼 | 끽 소리 | 결속 ×2 + 혼란 ×1 | 거미줄+홀림 중첩 | 결속 쌍 역이용 (여전히 유효) |
| 떠도는 눈 | 응시 | 기절 ×2 + 저주 ×1 | 해골+사슴 중첩 | 죽은 눈 조합 재료화 |
| 꿈나방 | 인분(鱗粉) | 어둠(blind) 2턴 | 정보 공격 단독 (일반몹 첫 blind) | 암산·기억 |
| 속삭이는 폴립 | 맥동 | 잠식 ×1 + 혼란 ×1 | 무덤 벌레 계승 | 시간 압박 관리 |
| 얼굴 없는 광신도 | 제물 | 약탈(plunder) ×2 | **약탈 데뷔** — 그 눈을 쓰면 코인을 잃는다 | 경제냐 전투냐 선택 |
| 비명 지르는 돌 | 굳히기 + **시작: 문턱 8** | 굳음 6, 3턴 | 골렘 혈통 3대 | 익숙한 해법, 더 단단한 몸 |
| 모래 사나이 E | 시간의 모래 | 마비 ×2 + 포박 ×1 | 쥐떼 강화 + 구속 | 리롤 아끼는 설계 |
| 언덕의 촉수 E | 휘감기 | 결속 ×3 + 포박 ×1 | 물풀 강화형 | 큰 덩어리 족보로 역이용 |
| 종지기 E | 침묵 / 종소리가 가둔다 | 직전 족보 봉인 2턴 / 혼란 ×2 | 기사 계승 + 정보 | 넓은 족보판 필수 |
| 자각몽의 왕 B | 꿈 고쳐쓰기 → (반피) 완전한 꿈 | 직전 봉인 2턴 + 어둠 → **혼란 ×5 (한 턴 전부 가림)** | 중첩의 정점 | 후반 1턴 암전을 버틸 준비 |
| 벌어진 아가리 B | 빛 삼키기 → (반피) 심연의 부름 | 물기(회복 있음) 2턴 → 잠식 ×2 | 거머리 극대화 → 잠식 | 삼키기 전 속전, 잠식 관리 |
| 속 빈 사제 | 거꾸로 된 축복 | **축복(blessing) ×2** — 그 칸은 높은 눈만 나옴 | **축복 데뷔** — 축복이 저주가 되는 곳 | 높은 눈 족보로 순응 |
| 성가대 유령 | 어긋난 화음 | 마비 ×2 | 쥐떼 혈통 | 리롤 절약 |
| 촛불 떼 | 확 타오르기 | 부패 ×2 | 파묻힌 자 계승 | 폭발 전 소모 |
| 거짓 성인 B | 거짓 사면 → (반피) 겸손을 강요한다 | 축복 ×3 → 하위 족보 봉인(노페어·원페어·투페어) 2턴 | **곰인형+축복의 합** | 높은 눈만 나오는데 낮은 족보 금지 → 상위 족보를 강요당한다 |
| 이름 없는 공포 최종 | 지운다 | 잠식 ×2 (매 시전 누적) | 잠식의 종착 — 다 차면 **공허의 부름**만 남는다 | 버티기 목표와 정합: 잠식이 곧 시계 |

## 5. 강도 예산·검증 계획 (구현 승인 시)

- 방해 강도 = "족보 기대 피해 감소율"로 계량: 2막 일반 20~30% / 정예 35~45% / 보스 45~55%,
  3막은 각 +5%p. 자동 플레이 시뮬(sim500)로 막별 도달률·전투 길이 실측 후 턴 수·수치 조정.
- 상태이상 지속·개수는 전부 데이터 (statuses.json turns + 행동 amount) — 데이터 매니저에서 바로 조정 가능.
- 잠식·부패처럼 시간형 기믹은 전투 길이와 상호작용이 커서 별도 스윕 (2막 평균 전투 5~7턴 기준).
