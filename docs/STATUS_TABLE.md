# 상태이상 · 지속효과 표

`node tools/statustable.mjs` 로 데이터에서 다시 뽑는다. 손으로 고치지 말 것.

## A. 주사위 칸에 붙는 상태이상 (13종)

칸 하나에 하나만 붙는다 — 나중 것이 먼저 것을 밀어내고, 밀려난 쪽은 그 자리에서 풀린다.
v3.94부터 내 턴이 **끝날 때** 1씩 줄고, 걸린 턴에는 줄지 않는다.

## E. 적 행동이 남기는 지속 방해

상태이상과 같은 문법으로 턴마다 줄어든다. 주사위 한 칸이 아니라 판 전체에 걸린다.

| 이름 | 효과 | 쓰는 곳 |
|---|---|---|
| 이빨 자국 | 리롤할 때마다 피해 | 3곳 |
| 가시 | 리롤할 때 지킨 주사위 하나당 피해 | 1곳 |
| 굳음 | 그 눈이 나오면 기절이 붙는다 | 2곳 |
| 물어채기 | 매 굴림 최고 눈을 잠근다 (+시전자 회복) | 2곳 |
| 스멀거림 | 족보 위력 미리보기를 가린다 | 3곳 |
| 흉내내기 | 직전에 쓴 족보를 봉인 | 4곳 |
| 솜 채우기 | 지정한 족보들을 봉인 | 3곳 |
| 벼름 흡수 | 쌓아둔 벼름을 빼앗는다 | 2곳 |
| 흩기 | 새겨둔 눈을 전부 푼다 | 2곳 |

## 비어 있는 자리

엔진에는 있는데 데이터가 거의/전혀 안 쓰는 것들.

- **플레이어 누적 독·출혈** — 쓰는 적 행동 0곳. engine 의 poison/bleed op 이 `player.dot` 을 쌓고 턴 끝에 tickDot 이 먹는데, 이 op 을 쓰는 적이 하나도 없다. 주사위에 붙는 출혈/독(즉발)과는 다른 장치다.
- **격노** — 행동으로 거는 곳 0곳. 맞을 때마다 힘이 붙는 반격형
- **반사** — 행동으로 거는 곳 0곳 (시작 상태로만 1종). 때리면 되돌아오는 기믹
- **적 재생** — 행동으로 거는 곳 1곳. 순 피해가 못 넘기면 영원히 못 잡는 기믹

### 엔진이 안 읽는 죽은 데이터

createBattle 이 보는 키는 `block`, `power`, `regen`, `enrage`, `reflect`, `undying` 뿐이다. 아래는 아무 일도 하지 않는다.

- 진흙 골렘(elite) cap 14
- 목 없는 기사(elite) ward 12
- 비명 지르는 돌(normal) ward 5
