# REDHOOD UI 표현 규칙 (v1.33)

기능이 늘면서 표시 방식이 기능마다 제각각이 됐다. 이제 화면에 뜨는 것은 **네 가지 형식**뿐이고, 새 기능은 반드시 이 넷 중 하나에 들어간다.

---

## 1. 표식 (badge) — 상태를 나타내는 작은 알약

`아이콘 + 값 (+ 덧붙임)`. 화면의 모든 "아이콘과 숫자" 는 예외 없이 이걸 통과한다.

```js
badge(tone, icon, value, { sub, cls, title })
```

**결(tone)은 셋뿐이고, 기준은 언제나 "나에게" 다.**

| 결 | 언제 | 색 | 예 |
|---|---|---|---|
| `good` | 내게 유리 | 초록 | 내 힘·집중·재생·벼름, **적에게 걸린** 약화·출혈·취약 |
| `bad` | 내게 불리 | 붉은 | 내가 물린 독·출혈, **적이 두른** 방어·강화 |
| `rule` | 규칙·제약 | 보라 | 정예·보스 기믹 (문턱·상한·요구) |

적의 디버프가 `good` 인 게 헷갈릴 수 있지만, 이 게임에서 색은 "누구 것인가" 가 아니라 **"나에게 좋은가"** 를 뜻한다. 화면을 훑을 때 초록이 많으면 유리, 붉은 게 많으면 불리 — 그 한 가지만 읽으면 된다.

아이콘은 그림(`assets/icons/*.png`)이 있으면 그림, 없으면 글자를 쓴다. **담는 틀은 어느 쪽이든 똑같다** — 예전에는 그림 아이콘과 이모지 알약이 서로 다른 모양이었다.

**덧붙임(`sub`)** 은 값 옆에 세로선으로 나뉘어 붙는 두 번째 숫자다. 벼름의 배수(`🔥4 │ ×3.0`), 요구의 남은 턴(`📜스트레이트 │ 2`) 처럼 "값이 둘인 표식" 에만 쓴다.

**놓이는 자리**

- 내 것: 체력바 바로 위 `.buff-strip`
- 적의 상태: 적 HP 숫자 옆 `.enemy-buffs`
- 적의 규칙(기믹): 예고 바로 아래 자기 줄 `.rule-row` — 상태와 섞지 않는다. 규칙은 "이번 판을 어떻게 풀 것인가" 라 읽는 무게가 다르다.

## 2. 낙인 (brand) — 주사위 위에 덮이는 것

주사위 한 칸에 얹히는 것은 전부 같은 네 겹으로 그린다.

```
틴트(색 곱연산) → 그림(있으면) → 테두리 → 이름표
```

상태이상 13종과 **새김(못 주사위)** 이 같은 형식을 쓴다. 예전에 새김은 📌 이모지 스티커였는데, 그것만 다른 언어를 쓰고 있었다.

## 3. 꼬리표 (tag) — 족보 줄의 작은 라벨

`.cat-tag`. 족보 이름 옆에 붙는 회색 라벨이다. 결이 필요하면 `t-` 를 붙인다.

- 기본: 족보 이름 (`노페어` `포카드`)
- `t-burst`: **⚡일격** — 벼름을 태우는 변형

일격도 예전엔 이름 앞의 인라인 이모지였는데, 이제 다른 라벨과 같은 형식이다.

## 4. 수치 (value) — 큰 숫자 하나

족보 줄 오른쪽 미리보기, HP 게이지 안의 숫자. 꾸미지 않는다. 일격 줄만 미리보기 숫자에 금빛을 준다 — 그 숫자가 벼름을 태운 결과라는 표시다.

---

## 새 기능을 넣을 때

1. **상태·자원인가** → 표식. 결을 셋 중에서 고르고, 값이 둘이면 `sub` 를 쓴다. 새 CSS 클래스를 만들지 않는다.
2. **주사위 한 칸에 붙는가** → 낙인. 틴트 색과 이름만 정하면 된다.
3. **족보 줄의 성질인가** → 꼬리표.
4. **셋 다 아닌가** → 그때 다시 이야기한다. 넷을 늘리는 건 마지막 수단이다.

CSS 에서 `.badge` 계열 바깥에 새 알약 스타일을 만드는 순간 다시 제각각이 된다.
