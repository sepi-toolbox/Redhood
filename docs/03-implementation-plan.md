## 3. 배포 규율 (ten runbook 준용)

1. 판을 바꾸면 `sw.js`의 `CACHE` 번호를 반드시 +1 (`redhood-vNN`).
2. 푸시는 Authorization 헤더 방식. 토큰은 `~/.config/redhood/token` (저장소 밖).
3. **git push ≠ 배포.** gh-pages 브랜치 갱신 후 게시본 확인이 끝나야 배포다.
4. 보고에는 무엇을/왜/밟은 함정/임의 판단을 명시한다.
5. 새 주사위·유물·족보는 승인 사항 — 명세에 없으면 만들지 말고 묻는다.
