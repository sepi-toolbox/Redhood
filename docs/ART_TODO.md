## 한 쌍으로 묶여 있는 것 (따로 뽑지 말 것)

1번과 2번은 **같은 상태의 덮개·아이콘**이다. `STATUS_ART_PROMPTS.md` 맨 앞의
**「상태별 한 쌍」 표**에서 한 줄을 통째로 가져가면 색·모티프가 자동으로 맞는다.

## 붙이는 법 (전부 회색 배경으로 뽑아서 주면 된다)

```
python3 tools/make_icon.py <원본.png> status_curse                  # 아이콘 (메달·색 자동)
python3 -c "import sys;sys.path.insert(0,'tools');import make_icon;make_icon.build_die('<원본.png>','curse')"   # 덮개
python3 -c "import sys;sys.path.insert(0,'tools');import make_icon;make_icon.build_ui('<원본.png>','coin')"     # UI 표식 (메달 없음)
```

> v3.14에서 `build_die`가 **배경색을 가운데에서 뽑도록** 고쳐졌다. 덮개는 가장자리에 붙어
> 귀퉁이를 물고 있어서, 예전처럼 귀퉁이를 배경으로 보면 키잉이 통째로 실패했다.

상자·유물은 기존 방식대로 대화에 올려주면 내가 키잉·리사이즈·연동한다.
