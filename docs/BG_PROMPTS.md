# REDHOOD 배경 프롬프트 — 10종 (복사용)

블록을 통째로 복사해서 쓰세요. 배경은 **키아트를 첨부하지 않아도 됩니다** (스타일 문구가 이미 안에 있습니다). 첨부한다면 `keyart_stilllife`.

**규격**: 세로 2:3 (게임에서 768×1152로 저장). 풀블리드라 배경 제거가 필요 없습니다.

**배경의 역할은 뒤로 물러나는 것입니다.** 게임에서 위에 어두운 오버레이를 한 겹 더 얹지만, 배경 자체가 밝거나 복잡하면 몬스터가 묻힙니다. 그래서 공통 블록에 "몬스터가 화면에서 가장 밝은 것으로 남게 어둡고 저대비로", "중간 띠는 단순하게", "아래 절반은 검정으로 떨어뜨릴 것"을 넣었습니다.

파일명은 `bg_{id}.jpg`로 저장됩니다. 올려주시면 리사이즈·최적화·연동까지 처리합니다.

등록하면 **해당 테마 전투만** 그 배경으로 바뀌고 나머지는 계속 숲을 씁니다. 하나씩 올려도 됩니다.
