## 1. 핵심 판타지

빨간망토가 어두운 숲에서 **운명의 주사위**를 굴린다. 같은 다섯 개의 주사위로
시작하지만, 숲을 지나며 주사위 자체를 갈아끼우고(사기주사위) 유물로 족보의
가치를 비틀어, 마지막엔 자신만의 확률 기계를 완성해 늑대를 잡는다.

## 2. 핵심 전투 루프

```
[내 턴]  주사위 5개 굴림 → (홀드 지정 후 리롤) × 남은 리롤 → 족보 선택·확정
         → 족보 점수만큼 적에게 피해
[적 턴]  적이 예고된 행동(의도 공개)으로 공격
→ 반복. 적 HP 0 = 승리, 내 HP 0 = 런 종료
```

| 규칙 | 프로토 값 | 비고 |
|---|---|---|
| 주사위 개수 | 5개 (교체는 가능, 개수 증감은 없음) | 턴 시작 시 빈 칸 — 굴림 버튼으로 시작 |
| 공격 대상 | 단일 공격 족보는 **대상 지정** (적 탭). 스트레이트 계열은 **전체 공격** | 적 1~2마리 조우 (scoring.json `target` 필드) |
| 리롤 | 턴당 2회 (첫 굴림 제외). **다시 굴릴 주사위를 탭으로 선택** — 기본은 전부 유지 | 유물로 +1 가능. v0.6에서 홀드→리롤 선택식으로 반전 |
| 족보 사용 | **소유한 족보만. 잠금·쿨다운 없음** — 매 턴 자유 선택 | 대신 족보마다 부가 능력이 달라 상황이 선택을 강제한다 |
| 성립 판정 | **성립하지 않는 족보는 선택 불가** (딤 처리) | 0점 버리기 폐지 (v0.5). 찬스가 항상 성립하므로 막히는 턴은 없음 |
| 상단 보너스 | 상단(1~6) 기본 점수 누적이 **40이 될 때마다** 즉시 추가 피해 25, 초과분 이월 (**반복 발동**) | 가계부 유물: 기준 40→30 |

**설계 의도 (v0.4)**: 족보 = 스킬. 피해와 부가 능력이 한 몸이라,
적의 예고(의도)에 맞춰 "이번 턴 어떤 족보가 정답인가"가 매 턴 바뀐다.
강타 예고엔 방어·회피 족보, 봉인엔 트리플, 준비 턴엔 화력 족보.
쿨다운이라는 인위적 제한 대신 상황이 연사를 자연스럽게 깨뜨린다.

## 3. 족보 — 변형(variant) 시스템 (v0.9)

**레벨 폐지.** 대신 각 족보는 **변형**을 보유한다 — 같은 판정·같은 피해, 다른 부가 능력.
**획득은 누적(v0.9, 성권 지시):** 보상에서 얻은 변형은 교체가 아니라 **추가**된다 — 같은 족보의 변형을 여러 개 동시에 보유·사용 가능.
전투 목록에서 같은 족보의 변형은 이웃하게 정렬되고, 줄 버튼 색은 변형 등급을 따른다(갈/청/**보라**/**금** — 4체계, v0.10).
이미 보유한 변형은 보상 풀에서 제외. 등급은 변형 단위(성립 난이도 × 능력 파워). 시작 족보는 **무기 선택**이 결정 (§5.1).
v0.10 재배분: 폭풍 질주·심판의 밤·핏빛 만월 = **epic**. (표의 rare 표기 중 이 3종은 epic으로 읽을 것 — ⚑ 검수)

피해: 상단=눈의 합 / 찬스=상위 3합 / 트리플·포카드=매칭합×2 / 풀하우스 25 / 스몰 30(전체) / 라지 40(전체) / 야찌 50.
**최종 피해** = `(기본 + 금박 기여) × 유물 배수 + 가산치 (+충전)`.

|---|---|---|---|

|  | 숲의 속삭임 | 다음 턴 리롤 +1 | uncommon |

## 4. 성장 축 — 사기주사위와 유물

전투 승리 보상: **범주(족보/사기주사위/유물)를 먼저 하나 추첨**하고, 해당 범주의
상자(📜 두루마리 / 🎲 가죽 주머니 / 🎁 숲의 상자)가 등장한다. 상자를 열면 **그 범주
안에서만 3택1** (스킵 가능). 범주 가중치는 act1.json `rewards.pool`.

### 4.1 사기주사위 — 효과 스펙트럼 (v0.10)

획득 시 보유 5개 중 하나와 교체한다 — 주사위 5개가 곧 "덱"이다.
주사위 효과는 **4가지 스펙트럼**으로 나뉜다 (성권 지시, v0.10):

| 유형 | 발동 조건 | 예 |

| ① 눈금형 | 면 구성 자체가 다름 | 납·짝눈·홀눈·외눈·높은 |
| ② 기여형 | 이 주사위가 **피해에 기여했을 때** | 금박·저주·송곳니 |
| ③ 확정형 | 기여 여부와 무관, **족보 확정 시마다** | 밀짚·잿불 |
| ④ 패시브 | 보유만 하면 상시 | 달빛·가시덤불 |

| 주사위 | 면 구성 | 효과 | 유형 | 등급 |

| **저주 주사위** | 1,1,6,6,6,6 | 탐스러운 눈 — 기여 시 **나도 3 피해** | ② | rare |

저주 주사위 자해로 HP 0이 되면 **패배 우선** (같은 확정에서 적이 전멸해도).

### 4.2 유물

| 유물 | 효과 |
|---|---|
| 은탄환 | **에이스 족보 점수 ×5** |
| 붉은 망토 | 매 턴 리롤 +1 |
| 사냥꾼의 부적 | 풀하우스 점수 +15 |
| 늑대 이빨 | 족보 확정 시마다 추가 피해 +3 |
| 빵부스러기 | 전투 승리 시 HP 4 회복 (0점 버리기 폐지로 재정의 — ⚑ 임의) |
| 가계부 | 상단 보너스 발동 기준 40 → 30 |

**유물 중첩 규칙 (프로토)**: 배수는 곱연산, 가산은 배수 적용 후 합산.
`최종 피해 = (족보 기본 점수 + 금박 기여) × 족보 배수 + 가산치`
발라트로식 인플레는 프로토에서 관찰 후 조정한다.

## 5. 런 구조

11층 분기 맵 (전투/엘리트/휴식/**만남**/보스), 휴식 30% 회복, 늑대 보스 2페이즈,
localStorage 이어하기. 적은 방어·상태효과 없이 **예고 공격 중심**으로 단순화
(주사위 게임의 결정 밀도가 이미 높으므로 적은 압박 역할에 집중).

### 5.1 무기 선택 인트로 (v0.10)

게임 시작 시 지도 대신 **첫 NPC(잿빛 방물장수)**를 먼저 만난다.
6종 무기 중 **3개가 무작위 제안**되고, 선택한 무기가 시작 족보 3종을 결정한다.
모든 세트에 찬스 계열 1종 포함 — 성립 족보가 없어 턴이 막히는 소프트락 방지 (⚑ 임의 판단).

| 무기 | 컨셉 | 시작 족보 |
|---|---|---|
| 🔫 사냥꾼의 총 | 한 방 화력 | 떠돌이의 직감 · 늑대 사냥탄(식스) · 묵직한 일격(포카드) |
| 🗡️ 녹슨 낫 | 휩쓸기 | 떠돌이의 직감 · 세 번 찍는 도끼(트리플) · 몰이사냥(스몰) |
| 🏮 붉은 랜턴 | 회복·지원 | 숲의 속삭임 · 약초 한 줌(트레이) · 할머니의 오두막(풀하우스) |
| ⛏️ 무덤지기의 삽 | 방어 | 떠돌이의 직감 · 참나무 방패(포스) · 가시 울타리(듀스) |
| 🏹 물푸레 쇠뇌 | 충전·연계 | 떠돌이의 직감 · 화약 재기(파이브) · 바람길(스몰) |
| 🔪 빵칼 단검 | 잔타 다수 | 숲의 속삭임 · 바늘 한 땀(에이스) · 붉은 망토 자락(듀스) |

⚑ 무기 이름·컨셉·시작 세트 전부 검수 대상 (data/events.json `weapons`).

### 5.2 대화 이벤트 — 만남(💬) (v0.10)

지도에 **만남** 방이 등장 (가중치 event 2 : battle 6). 입장하면 전투 화면과 같은 골격에서
적 위치=NPC, 주사위 위치=**검은 그라데이션 대사판**, 족보 위치=**선택지**가 표시된다.
같은 이벤트는 런 내 재등장하지 않는다 (모두 소진 시 반복 허용). 이벤트로는 죽지 않는다 (HP 최저 1).

| 이벤트 | 선택지 |
|---|---|
| 🧓 잿빛 노파 | 물약(HP+15) / 피의 거래(HP-8, 무작위 유물) / 지나친다 |
| 🪧 부러진 이정표 | 파헤친다(무작위 족보 변형) / 기도(최대 HP+4) / 지나친다 |
| 🕯️ 이끼 낀 제단 | 기도(HP+8) / 제물 훔치기(무작위 주사위, 교체) / 떠난다 |

⚑ 이벤트 3종의 대사·수치 전부 검수 대상 (data/events.json `events`).

적은 조우당 1~2마리. 다수전에서는 스트레이트(전체 공격)와 대상 선택(위험한 쪽 먼저)이 가치를 얻는다.

### 5.3 적 행동 6유형 (v0.11, 성권 지시)

| 유형 | 의도 표기 | 효과 |
|---|---|---|
| 공격 | ⚔️N | N 피해 (강화 누적분 합산 표기) |
| 방어 | 🛡N | 방어 N — 자기 다음 행동 때까지 받는 피해 흡수. 막으면 "🛡막음" 표시 |
| 혼란 | 🌀 | 다음 턴 무작위 주사위 N개가 뒤틀림(보라) — **다시 굴릴 수 없음** (⚑ 효과 정의 임의) |
| 강화 | 💪 | 공격력 +N, 전투 내 영구 누적 |
| 치료 | 💚N | 자신 HP N 회복 (초기 HP 상한) |
| 의문 | ❓ | 의도를 숨김 — 실제 행동은 위 유형 중 하나 |
| 혼합 | 병기 (⚔️4 🌀 등) | 공격혼란(까마귀 날갯짓)·공격강화(들개 사냥)·방어혼란(가시 세우기)·방어강화(우두머리 울부짖음) |
