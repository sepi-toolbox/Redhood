## 1. 핵심 판타지

빨간망토가 어두운 숲에서 **운명의 주사위**를 굴린다. 같은 다섯 개의 주사위로
시작하지만, 숲을 지나며 주사위 자체를 갈아끼우고(사기주사위) 유물로 족보의
가치를 비틀어, 마지막엔 자신만의 확률 기계를 완성해 늑대를 잡는다.

## 2. 핵심 전투 루프

```
[내 턴]  주사위 5개 굴림 → (홀드 지정 후 리롤) × 남은 리롤 → 족보 선택·확정
         → 족보 점수만큼 적에게 피해
[적 턴]  적이 예고된 행동(의도 공개)으로 공격
→ 반복. 적 HP 0 = 승리, 내 HP 0 = 런 종료
```

| 규칙 | 프로토 값 | 비고 |
|---|---|---|
| 주사위 개수 | 5개 (교체는 가능, 개수 증감은 없음) | |
| 리롤 | 턴당 2회 (첫 굴림 제외). 홀드한 주사위는 유지 | 유물로 +1 가능 |
| 족보 사용 | **소유한 족보만, 잠금 없음.** 상위 족보는 쿨다운 | v0.2의 전투당 1회 잠금 폐지 |
| 0점 처리 | 어떤 족보든 현재 눈으로 확정 가능 (0점 포함) | 턴 넘기기 겸용 |
| 상단 보너스 | 전투 중 상단(1~6) 합계 63 이상 도달 시 즉시 추가 피해 35 (전투당 1회) | |

**설계 의도 (v0.3)**: "내가 모은 족보를 펑펑 터트리는" 빌드 크래프팅 구조.
시작 족보(상단 6종+찬스)로 최저선을 보장하고, 상위 족보는 드랍으로 구하며,
중복 드랍은 레벨업이 된다. 잠금 대신 쿨다운·적의 봉인이 연사를 제어한다.

## 3. 족보 — 소유·레벨·쿨다운

| 족보 | 점수(=피해) | 시작 소유 | 쿨다운 | 드랍 등급 |
|---|---|---|---|---|
| 에이스~식스 (상단) | 해당 눈의 합 | ○ | 0 | common (레벨업만) |
| 찬스 | 전체 합 | ○ | 1턴 | common (레벨업만) |
| 트리플 | 전체 합 | ✕ | 1턴 | common |
| 포카드 | 전체 합 | ✕ | 2턴 | uncommon |
| 풀하우스 | 25 | ✕ | 2턴 | uncommon |
| 스몰 스트레이트 (4연속) | 30 | ✕ | 2턴 | uncommon |
| 라지 스트레이트 (5연속) | 40 | ✕ | 3턴 | rare |
| 야찌 (5개 동일) | 50 | ✕ | 3턴 | rare |

**레벨**: 같은 족보를 다시 드랍받으면 레벨업 (최대 Lv3). 점수 ×레벨.
**최종 피해** = `(기본 + 금박 기여) × 레벨 × 유물 배수 + 가산치`.
**적의 봉인**: 일부 적은 "마지막으로 쓴 족보"를 2턴 봉인한다 — 주력기 연사에 대한 견제.
**적 HP 스케일링**: 층수당 +10% (act1.json `hpScalePerFloor`) — 성장하지 않으면 못 뚫는 압박.

## 4. 성장 축 — 사기주사위와 유물

전투 승리 보상으로 **사기주사위 또는 유물 중 1개**를 선택한다 (3택1, 스킵 가능).

### 4.1 사기주사위

주사위의 **면(faces) 구성이 다르거나 특수 규칙**을 가진 주사위.
획득 시 보유 5개 중 하나와 교체한다 — 주사위 5개가 곧 "덱"이다.

| 주사위 | 면 구성 | 특수 규칙 |
|---|---|---|
| 금박 주사위 | 1~6 | 족보에 기여하면 **자기 눈만큼 추가 피해** (기여 점수 배가) |
| 납 주사위 | 1,2,3,4,6,6 | — (6 확률 2배) |
| 짝눈 주사위 | 2,2,4,4,6,6 | — (짝수만) |
| 홀눈 주사위 | 1,1,3,3,5,5 | — (홀수만) |
| 외눈 주사위 | 1,1,1,1,1,6 | — (에이스 빌드용) |
| 높은 주사위 | 3,4,4,5,5,6 | — (하이롤) |
| 쌍둥이 주사위 | 1~6 | 굴린 뒤 다른 주사위 하나와 같은 눈으로 복사됨 → **프로토 제외**, 아이디어만 기록 |

⚑ 금박·은탄환 외 주사위/유물 구성은 성권님 두 예시에서 확장한 **제안**이다.
채택·수치는 전부 검수 대상 (data/dice.json, data/relics.json).

### 4.2 유물

| 유물 | 효과 |
|---|---|
| 은탄환 | **에이스 족보 점수 ×5** |
| 붉은 망토 | 매 턴 리롤 +1 |
| 사냥꾼의 부적 | 풀하우스 점수 +15 |
| 늑대 이빨 | 족보 확정 시마다 추가 피해 +3 |
| 빵부스러기 | 0점으로 족보를 버릴 때 HP 3 회복 |
| 가계부 | 상단 보너스 발동 기준 63 → 50 |

**유물 중첩 규칙 (프로토)**: 배수는 곱연산, 가산은 배수 적용 후 합산.
`최종 피해 = (족보 기본 점수 + 금박 기여) × 족보 배수 + 가산치`
발라트로식 인플레는 프로토에서 관찰 후 조정한다.

## 5. 런 구조 (v0.1에서 유지)

11층 분기 맵 (전투/엘리트/휴식/보스), 휴식 30% 회복, 늑대 보스 2페이즈,
localStorage 이어하기. 적은 방어·상태효과 없이 **예고 공격 중심**으로 단순화
(주사위 게임의 결정 밀도가 이미 높으므로 적은 압박 역할에 집중).

| 적 압박 수단 (프로토) | 내용 |
|---|---|
| 평타 | 예고된 수치만큼 피해 |
| 강타 준비 | 한 턴 쉬고 다음 턴 큰 피해 (의도로 예고) |
| (보스 2페이즈) | HP 50% 이하에서 패턴 교체·공격 강화 |
