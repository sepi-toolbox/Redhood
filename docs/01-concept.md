## 1. 핵심 판타지

빨간망토가 어두운 숲에서 **운명의 주사위**를 굴린다. 같은 다섯 개의 주사위로
시작하지만, 숲을 지나며 주사위 자체를 갈아끼우고(사기주사위) 유물로 족보의
가치를 비틀어, 마지막엔 자신만의 확률 기계를 완성해 늑대를 잡는다.

## 2. 핵심 전투 루프

```
[내 턴]  주사위 5개 굴림 → (홀드 지정 후 리롤) × 남은 리롤 → 족보 선택·확정
         → 족보 점수만큼 적에게 피해
[적 턴]  적이 예고된 행동(의도 공개)으로 공격
→ 반복. 적 HP 0 = 승리, 내 HP 0 = 런 종료
```

| 규칙 | 프로토 값 | 비고 |
|---|---|---|
| 주사위 개수 | 5개 (교체는 가능, 개수 증감은 없음) | 턴 시작 시 빈 칸 — 굴림 버튼으로 시작 |
| 공격 대상 | 단일 공격 족보는 **대상 지정** (적 탭). 스트레이트 계열은 **전체 공격** | 적 1~2마리 조우 (scoring.json `target` 필드) |
| 리롤 | 턴당 2회 (첫 굴림 제외). 홀드한 주사위는 유지 | 유물로 +1 가능 |
| 족보 사용 | **소유한 족보만. 잠금·쿨다운 없음** — 매 턴 자유 선택 | 대신 족보마다 부가 능력이 달라 상황이 선택을 강제한다 |
| 성립 판정 | **성립하지 않는 족보는 선택 불가** (딤 처리) | 0점 버리기 폐지 (v0.5). 찬스가 항상 성립하므로 막히는 턴은 없음 |
| 상단 보너스 | 상단(1~6) 기본 점수 누적이 **40이 될 때마다** 즉시 추가 피해 25, 초과분 이월 (**반복 발동**) | 가계부 유물: 기준 40→30 |

**설계 의도 (v0.4)**: 족보 = 스킬. 피해와 부가 능력이 한 몸이라,
적의 예고(의도)에 맞춰 "이번 턴 어떤 족보가 정답인가"가 매 턴 바뀐다.
강타 예고엔 방어·회피 족보, 봉인엔 트리플, 준비 턴엔 화력 족보.
쿨다운이라는 인위적 제한 대신 상황이 연사를 자연스럽게 깨뜨린다.

## 3. 족보 — 피해 + 부가 능력 (시작: 찬스·듀스·트리플)

| 족보 | 피해 | 부가 능력 | 시작 | 등급 |
|---|---|---|---|---|
| 에이스 | 1 합 | 다음 턴 리롤 +1 | ✕ | common |
| 듀스 | 2 합 | 방어도 +점수×2 | **○** | common |
| 트레이 | 3 합 | HP 3 회복 | ✕ | common |
| 포스 | 4 합 | 방어도 +점수 | ✕ | common |
| 파이브 | 5 합 | 다음 족보 피해 +5 | ✕ | common |
| 식스 | 6 합 | 없음 (순수 화력) | ✕ | common |
| 찬스 | **상위 눈 3개의 합** | 없음 (언제나 성립) | **○** | common |
| 트리플 | **같은 눈들의 합 ×2** | 해제 — **디버프 개편 대기** | **○** | common |
| 포카드 | **같은 눈들의 합 ×2** | 적 다음 행동 취소 | ✕ | rare |
| 풀하우스 | 25 | 방어도 +15 | ✕ | uncommon |
| 스몰 스트레이트 | 30 | 이번 적 공격 회피 | ✕ | uncommon |
| 라지 스트레이트 | 40 | 회피 + 다음 턴 리롤 +1 | ✕ | rare |
| 야찌 | 50 | 적 행동 취소 + 방어도 20 | ✕ | rare |

**레벨**: 중복 드랍 = 레벨업 (최대 Lv3), 피해에만 ×레벨. 부가 능력 수치는 고정.
단, `levelFlat` 필드가 있는 족보는 ×배수 대신 **레벨당 +N 고정 피해** — 찬스는 +2/레벨 (보험은 미미하게만 성장).
**최종 피해** = `(기본 + 금박 기여) × 레벨 × 유물 배수 + 가산치 (+충전)`.
**방어도**: 확정 직후의 적 행동에만 유효 (내 턴 시작 시 소멸).
**적 HP 스케일링**: 층수당 +10%.

## 4. 성장 축 — 사기주사위와 유물

전투 승리 보상: **범주(족보/사기주사위/유물)를 먼저 하나 추첨**하고, 해당 범주의
상자(📜 두루마리 / 🎲 가죽 주머니 / 🎁 숲의 상자)가 등장한다. 상자를 열면 **그 범주
안에서만 3택1** (스킵 가능). 범주 가중치는 act1.json `rewards.pool`.

### 4.1 사기주사위

주사위의 **면(faces) 구성이 다르거나 특수 규칙**을 가진 주사위.
획득 시 보유 5개 중 하나와 교체한다 — 주사위 5개가 곧 "덱"이다.

| 주사위 | 면 구성 | 특수 규칙 |
|---|---|---|
| 금박 주사위 | 1~6 | 족보에 기여하면 **자기 눈만큼 추가 피해** (기여 점수 배가) |
| 납 주사위 | 1,2,3,4,6,6 | — (6 확률 2배) |
| 짝눈 주사위 | 2,2,4,4,6,6 | — (짝수만) |
| 홀눈 주사위 | 1,1,3,3,5,5 | — (홀수만) |
| 외눈 주사위 | 1,1,1,1,1,6 | — (에이스 빌드용) |
| 높은 주사위 | 3,4,4,5,5,6 | — (하이롤) |
| 쌍둥이 주사위 | 1~6 | 굴린 뒤 다른 주사위 하나와 같은 눈으로 복사됨 → **프로토 제외**, 아이디어만 기록 |

⚑ 금박·은탄환 외 주사위/유물 구성은 성권님 두 예시에서 확장한 **제안**이다.
채택·수치는 전부 검수 대상 (data/dice.json, data/relics.json).

### 4.2 유물

| 유물 | 효과 |
|---|---|
| 은탄환 | **에이스 족보 점수 ×5** |
| 붉은 망토 | 매 턴 리롤 +1 |
| 사냥꾼의 부적 | 풀하우스 점수 +15 |
| 늑대 이빨 | 족보 확정 시마다 추가 피해 +3 |
| 빵부스러기 | 전투 승리 시 HP 4 회복 (0점 버리기 폐지로 재정의 — ⚑ 임의) |
| 가계부 | 상단 보너스 발동 기준 40 → 30 |

**유물 중첩 규칙 (프로토)**: 배수는 곱연산, 가산은 배수 적용 후 합산.
`최종 피해 = (족보 기본 점수 + 금박 기여) × 족보 배수 + 가산치`
발라트로식 인플레는 프로토에서 관찰 후 조정한다.

## 5. 런 구조 (v0.1에서 유지)

11층 분기 맵 (전투/엘리트/휴식/보스), 휴식 30% 회복, 늑대 보스 2페이즈,
localStorage 이어하기. 적은 방어·상태효과 없이 **예고 공격 중심**으로 단순화
(주사위 게임의 결정 밀도가 이미 높으므로 적은 압박 역할에 집중).

적은 조우당 1~2마리. 다수전에서는 스트레이트(전체 공격)와 대상 선택(위험한 쪽 먼저)이 가치를 얻는다.

| 적 압박 수단 (프로토) | 내용 |
|---|---|
| 평타 | 예고된 수치만큼 피해 |
| 강타 준비 | 한 턴 쉬고 다음 턴 큰 피해 (의도로 예고) |
| (보스 2페이즈) | HP 50% 이하에서 패턴 교체·공격 강화 |
