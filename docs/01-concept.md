## 1. 핵심 판타지

빨간망토가 어두운 숲에서 **운명의 주사위**를 굴린다. 같은 다섯 개의 주사위로
시작하지만, 숲을 지나며 주사위 자체를 갈아끼우고(사기주사위) 유물로 족보의
가치를 비틀어, 마지막엔 자신만의 확률 기계를 완성해 늑대를 잡는다.

## 2. 핵심 전투 루프

```
[내 턴]  주사위 5개 굴림 → (홀드 지정 후 리롤) × 남은 리롤 → 족보 선택·확정
         → 족보 점수만큼 적에게 피해
[적 턴]  적이 예고된 행동(의도 공개)으로 공격
→ 반복. 적 HP 0 = 승리, 내 HP 0 = 런 종료
```

| 규칙 | 프로토 값 | 비고 |
|---|---|---|
| 주사위 개수 | 5개 (교체는 가능, 개수 증감은 없음) | 턴 시작 시 빈 칸 — 굴림 버튼으로 시작 |
| 공격 대상 | 단일 공격 족보는 **대상 지정** (적 탭). 스트레이트 계열은 **전체 공격** | 적 1~2마리 조우 (scoring.json `target` 필드) |
| 리롤 | 턴당 2회 (첫 굴림 제외). **다시 굴릴 주사위를 탭으로 선택** — 기본은 전부 유지 | 유물로 +1 가능. v0.6에서 홀드→리롤 선택식으로 반전 |
| 족보 사용 | **소유한 족보만. 잠금·쿨다운 없음** — 매 턴 자유 선택 | 대신 족보마다 부가 능력이 달라 상황이 선택을 강제한다 |
| 성립 판정 | **성립하지 않는 족보는 선택 불가** (딤 처리) | 0점 버리기 폐지 (v0.5). 찬스가 항상 성립하므로 막히는 턴은 없음 |

**설계 의도 (v0.19)**: 족보 = 스킬, 능력 = **전투 내 지속 버프/디버프** (성권 지시 — 단발성 자제).
버프 족보로 빌드업하고 데미지 족보로 폭발시키는 전투 내 플랜이 핵심.
즉발은 방어도만 유지. 회피·행동취소·"다음 1회"류는 전부 폐지.

| 효과 | 대상 | 내용 |
|---|---|---|
| 🗡️ 힘 | 나 | 모든 족보 피해 +N (전투 내 누적) |
| 🎲 집중 | 나 | 매 턴 리롤 +N |
| ❤️ 재생 | 나 | 매 턴 시작 HP +N |
| 🛡 방어도 | 나/적 | 즉발 유지 — 다음 적/자기 행동까지 흡수. 적 방어도 체력바에 실드 표시 |
| 🔻 약화 | 적 | 공격력 -N (맞은 대상, 전투 내 지속) |
| 🩸 출혈 | 적 | 행동할 때마다 N 피해(방어 무시) 후 스택 -1. 출혈사 가능 |
| 🎯 취약 | 적 | 받는 피해 +N (맞은 대상, 전투 내 지속) |

UI: 내 버프는 체력바 위 칩 + 길게 눌러 상세. 적에게 걸린 효과는 적 길게 눌러 확인.

## 3. 족보 — 변형(variant) 시스템 (v0.9)

**레벨 폐지.** 대신 각 족보는 **변형**을 보유한다 — 같은 판정·같은 피해, 다른 부가 능력.
**획득은 누적(v0.9, 성권 지시):** 보상에서 얻은 변형은 교체가 아니라 **추가**된다 — 같은 족보의 변형을 여러 개 동시에 보유·사용 가능.
전투 목록에서 같은 족보의 변형은 이웃하게 정렬되고, 줄 버튼 색은 변형 등급을 따른다(갈/청/**보라**/**금** — 4체계, v0.10).
이미 보유한 변형은 보상 풀에서 제외. 등급은 변형 단위(성립 난이도 × 능력 파워). 시작 족보는 **무기 선택**이 결정 (§5.1).

**v0.18 (성권 지시): 상단 6종(에이스~식스)·상단 보너스 게이지 폐지** — "조합이 중요하지 특정 눈이 중요한 게 아니다."
족보는 순수 조합 9종: 노페어 → **원페어(신규)** → 투페어 → 트리플 → 풀하우스 → 포카드 → 스몰 → 라지 → 야찌.

피해(v0.18): 노페어=가장 높은 눈 하나 / **원페어=같은 눈들의 합 (성립 99.9%, EV 12.4 — 빵과 버터)** / 투페어=두 쌍의 합 ×1.25(내림) / 트리플=매칭합×1.5(내림) / 포카드=매칭합×3 / 풀하우스 35 / 스몰 28(전체) / 라지 60(전체) / 야찌 70.
게이지 폐지에 따라 유물 재해석: 가계부→상점 -20%, 은저울→🪙 +25%, 가죽 장갑→투페어 +6, 은탄환→포카드 2배, 사냥탄·상단 변형 12종 삭제.

**밸런스 방법(v0.12)**: 몬테카를로 20만 회로 족보별 성립률·기대피해를 측정하고, 부가 능력을
피해환산가치(방어 0.9/점·회복 1/점·리롤 3·다음피해 0.9/점·회피 11·행동취소 10)로 정량화.
상단 보너스 실효 ×1.625, 전체 공격 ×1.2 반영. **변형 26종의 턴가치를 16.3~22.2로 정렬**
(야찌 2종은 잭팟 정체성 — 전용 추구 시 기대치는 낮지만 성공 시 ~4턴치 가치).
**v0.16 (성권 지시)**: 찬스 → **노페어** — 판정은 언제나 성립, 피해는 **가장 높은 눈 하나**(EV 5.9).
피해 기대치를 완전히 포기한 순수 보험/유틸 슬롯이 됨. 변형 능력(속삭임의 리롤 등)이 실질 가치.
막히는 턴 방지 역할은 유지. ⚑ 관찰: 노페어만 남은 굴림의 턴 가치가 매우 낮아짐 — 의도된 리스크.

**v0.15 찬스 도미넌스 해소 (성권 지적)**: 시뮬 결과 늑대 사냥탄이 직감을 즉시 피해로 이기는 경우가
**10.6%**(6이 4개 이상일 때뿐)로 사실상 지배당하고 있었다. 수정: ① 찬스 = **서로 다른 눈** 상위 3합
(같은 눈은 한 번만 — 뭉칠수록 찬스가 약해져 보험 역할로 고정, EV 16.4→13.8) ② 사냥탄에
**상단 게이지 +5** 부여 (게이지 엔진 정체성). 결과: 식스 추구 시 사냥탄이 즉시 피해로도 45%,
게이지 포함 76% 우위 — 서로 다른 상황에서 이기는 관계로 전환.
**최종 피해** = `(기본 + 금박 기여) × 유물 배수 + 가산치 (+충전)`.

## 4. 성장 축 — 사기주사위와 유물

**보상 경제 (v0.13, 성권 지시)** — 등급은 출처가 결정한다:

| 출처 | 족보·주사위 | 유물 | 비고 |
|---|---|---|---|
| 일반 전투 | 커먼~언커먼 | 없음 | 🪙 12~18 |
| 엘리트 | 언커먼~레어 | 일반 유물 (풀 가중 30%) | 🪙 25~35 |
| 보스 | **전설(에픽)** 족보/주사위 | **정예 유물** | 2단계 전리품: 정예 유물 3택 → 전설 3택 |
| 만남(이벤트) | 무엇이든 | 무엇이든 | 단, 상응하는 대가(HP 등) 지불 |
| 상점(🧺) | 커먼~레어 주사위 (전설 없음) | 일반 유물 | 🪙로 구매 — 주사위 25/40/60, 유물 45 |

전투 승리 시 범주 상자 → 3택1 구조는 유지. **족보 누적 보정**: 보유 변형이 많아질수록
주사위 확률이 올라간다 (3개 초과분 1개당 +4, 족보 가중의 최대 70%까지 이전 —
족보만 쌓여 복잡해지는 것 방지, ⚑ 계수 검수). 화폐 🪙 코인은 전투 승리로만 획득 (⚑ 임의 판단).

### 4.1 사기주사위 — 효과 스펙트럼 (v0.10)

획득 시 보유 5개 중 하나와 교체한다 — 주사위 5개가 곧 "덱"이다.
주사위 효과는 **4가지 스펙트럼**으로 나뉜다 (성권 지시, v0.10):

| 유형 | 발동 조건 | 예 |
|---|---|---|
| ① 눈금형 | 면 구성 자체가 다름 | 납·짝눈·홀눈·외눈·높은 |
| ② 기여형 | 이 주사위가 **피해에 기여했을 때** | 금박·저주·송곳니 |
| ③ 확정형 | 기여 여부와 무관, **족보 확정 시마다** | 밀짚·잿불 |
| ④ 패시브 | 보유만 하면 상시 | 달빛·가시덤불 |

| 주사위 | 면 구성 | 효과 | 유형 | 등급 |
|---|---|---|---|---|
| 나무 주사위 | 1~6 | — | — | common |
| 납 주사위 | 1,2,3,4,6,6 | 6 확률 2배 | ① | uncommon |
| 짝눈 주사위 | 2,2,4,4,6,6 | 짝수만 | ① | uncommon |
| 홀눈 주사위 | 1,1,3,3,5,5 | 홀수만 | ① | uncommon |
| 높은 주사위 | 3,4,4,5,5,6 | 낮은 눈 없음 | ① | uncommon |
| 외눈 주사위 | 1,1,1,1,1,6 | 같은 눈 몰빵 — 야찌(70) 도박용 | ① | rare |
| 금박 주사위 | 1~6 | 기여 시 자기 눈만큼 추가 피해 | ② | **epic** |
| **저주 주사위** | 1,1,6,6,6,6 | 탐스러운 눈 — 기여 시 **나도 3 피해** | ② | rare |
| 송곳니 주사위 | 1~6 | 기여 시 HP 2 회복 (흡혈) | ② | rare |
| **밀짚 주사위** | 1,1,2,2,3,3 | 눈은 낮지만 확정 시마다 방어 3 | ③ | common |
| 잿불 주사위 | 2,2,3,3,4,4 | 확정 시마다 HP 1 회복 | ③ | uncommon |
| 달빛 주사위 | 1,1,2,3,4,5 | 눈은 흐릿, 매 턴 리롤 +1 | ④ | rare |
| 가시덤불 주사위 | 1,2,2,3,3,4 | 매 턴 시작 시 방어 2 | ④ | uncommon |

⚑ 신규 6종(저주·송곳니·밀짚·잿불·달빛·가시덤불)의 면 구성·수치·등급 전부 검수 대상 (data/dice.json).
저주 주사위 자해로 HP 0이 되면 **패배 우선** (같은 확정에서 적이 전멸해도).
