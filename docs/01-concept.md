## 1. 핵심 판타지

빨간망토가 어두운 숲을 지나 할머니의 집 — 그리고 그 안에 도사린 **늑대**에게 향한다.
숲은 매 런마다 모습을 바꾸고, 소녀는 세 가지 유산 중 하나만을 손에 쥔 채 출발한다.

톤은 다크 페어리테일. 다키스트 던전처럼 "버티고, 소모되고, 그래도 나아가는" 압박감을
카드 리소스 관리로 표현한다. 화면은 밝지 않고, 숲은 친절하지 않다.

## 2. 핵심 루프

```
런 시작 → 무기(직업) 선택 → 맵 노드 선택 → 전투/휴식/이벤트
        → 보상(카드 3택1 등) → 덱 성장 → … → 보스(늑대) → 클리어 or 사망 → 다음 런
```

전투와 로그라이크 골자는 **프로토 기준 슬레이 더 스파이어와 동일**하게 간다.
(드로우 5장, 턴제, 적 의도 공개, 방어도는 턴 종료 시 소멸, 사망 시 런 종료.)
변주는 프로토 완성 후에 준다 — 지금은 검증된 뼈대 위에 무기 시스템만 얹는다.

**단, 공용 에너지는 없다.** 슬더스의 에너지 3 대신, 카드 코스트는 **무기 자원 그 자체**다.
이것이 이 게임의 1차 차별점이다.

## 3. 무기 3종 — 클래스 정체성

무기가 곧 직업(클래스)이다. 런 시작 시 하나를 선택하며, 자원 체계가 서로 완전히 다르다.

### 3.1 총 — "사냥꾼" (자원: 탄환)

| 항목 | 내용 |
|---|---|
| 자원 | 탄환. 최대 6발 (약실 컨셉) |
| 지불 | 카드 코스트 = 탄환 소모 |
| 회복 | 자동 회복 없음. **장전(탄환 보충) 카드**로만 채운다 |
| 전투 시작 | 6발 만장전 상태로 시작 |

플레이 감각: **쏘는 턴과 장전하는 턴의 리듬**. 화력은 셋 중 최고지만,
장전 카드가 손에 안 잡히면 빈 총으로 버텨야 한다. 덱 구성에서 장전:사격
비율 관리가 곧 실력이 되는 무기.

### 3.2 랜턴 — "등불지기" (자원: 기름)

| 항목 | 내용 |
|---|---|
| 자원 | 기름(빛). 매 턴 시작 시 **+3** 충전 |
| 지불 | 카드 코스트 = 기름 소모 |
| 축적 | 쓰지 않은 기름은 이월된다. 상한 9 (프로토 기준) |
| 전투 시작 | 기름 3으로 시작 |

플레이 감각: **저축과 방출**. 싼 카드로 버티며 기름을 모았다가 고코스트
카드를 터뜨리는 곡선. 화상(지속 피해)·제어 계열 효과가 정체성.
슬더스 에너지와 가장 유사하지만 "이월"이 전략 축을 만든다.

### 3.3 낫 — "수확자" (자원 없음 / 열광 게이지)

| 항목 | 내용 |
|---|---|
| 자원 | 없음. 카드는 코스트 없이 낼 수 있다 |
| 대가 | 공격적 카드 사용 시 **열광 게이지 상승** |
| 제어 | **절제 카드**로 열광을 낮춘다 |
| 게이지 | 0~10. 전투 시작 시 0 |

열광 단계 (프로토 기준 수치, 밸런싱 대상):

| 단계 | 구간 | 효과 |
|---|---|---|
| 평정 | 0~3 | 패널티 없음 |
| 흥분 | 4~6 | 받는 피해 +25% |
| 폭주 | 7~9 | 받는 피해 +50%, 턴 종료 시 자해 피해 2 |
| 한계 | 10 | 즉시 손패 전체 버림, 턴 강제 종료, 열광 7로 감소 |

플레이 감각: **과열 관리**. 코스트가 없으니 이론상 손패를 전부 던질 수 있지만,
그 대가는 게이지로 돌아온다. 몰아칠 타이밍과 절제할 타이밍을 읽는 무기.

### 3.4 중립 카드

무기와 무관하게 등장하는 공용 카드군. 코스트 처리 통일 규칙(제안):

> 중립 카드의 코스트 N은 **장착 무기의 화폐로 환산**된다.
> 총 → 탄환 N 소모 · 랜턴 → 기름 N 소모 · 낫 → 열광 N 상승.

이 규칙이면 중립 카드도 테이블에 코스트 숫자 하나만 적으면 되고,
낫에게는 "무비용이지만 열광이 오르는" 기존 문법과 충돌하지 않는다.
→ **오픈 이슈 #1** 참고. 확정 필요.

## 4. 전투 골자 (슬더스 준거)

| 요소 | 프로토 사양 |
|---|---|
| 드로우 | 매 턴 5장. 턴 종료 시 손패 전부 버림 |
| 덱 순환 | 뽑을 덱 소진 시 버림 더미를 섞어 재생성 |
| 적 의도 | 다음 행동(공격력·효과) 아이콘 공개 |
| 방어도 | 피해를 먼저 흡수, 본인 턴 시작 시 소멸 |
| 상태효과 | 힘, 약화, 취약, 화상, 출혈 (프로토 5종) |
| HP | 전투 간 유지. 0이 되면 런 종료 |
