# v3.8 밸런스 초벌 스윕 보고 (조우 전수 · 기믹 ON/OFF 대조)

측정: `node test/encsweep.mjs 120` (기본 빌드) / `... 120 strong` (강화 빌드 — 정예·보스용).
각 적을 120판 × 2회(기믹 있는 그대로 / 테마·시작버프 제거 대조군) 붙여 **기믹의 실제 물림(Δ손실)** 을 쟀다.

## 읽는 법·한계 (중요)

- **Δ손실이 기믹의 값이다.** 절대 승률은 봇·체크포인트 빌드(변형·유물 성장 미반영)의 한계로 실플레이보다 낮다.
- 봇은 **정보 공격(눈 가림·위력 숨김)에 면역**이다 — 엔진 내부 값을 그대로 보기 때문. 홀림·곡소리·어둠 계열의 Δ는 과소평가.
- 봇은 리롤을 아껴 쓰므로 **리롤 세금·마비 계열도 과소평가**된다.
- 2·3막 보스의 절대 승률 0%는 "그 시점의 진짜 성장(에픽 변형·유물·벼름 빌드)"을 빌드로 재현하지 못한 것 — 기믹 문제가 아님. 실플레이 감각과 함께 판정해야 한다.
